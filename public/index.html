AOI Labeler v3

步骤1（必选）
上传场景底图（jpg/png）
步骤2（可选）
上传眼动点 CSV（含列：Gaze Point X[px]、Gaze Point Y[px]）

批处理（1 张底图 + 多个 CSV）

交互（v3）：
- 滚轮缩放，空白处拖动画布平移
- 点击 polygon 选中；拖顶点可编辑
- 按住 Shift 拖动选中 polygon 可整体移动
- 绘制时点击首点附近自动闭合
- 快捷键：Enter 闭合保存 / Esc 取消绘制 / Delete 删除选中 polygon
- Undo/Redo：Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Y 或 Ctrl/Cmd+Shift+Z 重做
